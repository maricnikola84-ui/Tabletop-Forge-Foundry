# World Tools

Import, migration, cleanup, repair, and diagnostics tooling for Foundry/Forge worlds belongs here.

Rules:

- always support dry-run/audit when practical;
- back up/export before destructive world migrations;
- target only known project-owned documents during cleanup;
- preserve stable IDs/references when updating existing content;
- prefer Forge Import Wizard repair/update workflows over deleting/reimporting entire worlds;
- report exactly what changed.
