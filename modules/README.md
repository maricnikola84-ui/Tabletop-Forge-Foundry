# Modules

Custom Foundry modules belong here.

Priority modules for this repository are N5EB 3.1.1 automation, Enemy Forge, diagnostics, and campaign/import tooling.

Rules:

- do not bundle official N5EB compendium documents when runtime resolution is sufficient;
- preserve stable module IDs for in-place upgrades;
- include module-level README/changelog/build report;
- include audit/resync/cleanup tools for automation-heavy modules;
- keep old overlapping builds archived or disabled rather than active together.
